01Présentations

Une fenêtre. Quatre façons de voir vos fichiers.

Changez d’une touche. Chaque dossier retient sa présentation, sa taille d’icônes et son tri.

De vraies vignettes.

Photos et documents montrent leur contenu. Placez les icônes librement ou alignez-les sur la grille.

  • Taille et espacement des icônes par dossier
  • Tracez un rectangle de sélection, tapez un nom pour y sauter

Tous les détails, triables.

Nom, date, taille et type dans des colonnes triables. Les dossiers se déplient sur place, vous ne perdez jamais le fil.

  • Cliquez sur un en-tête pour trier, encore une fois pour inverser
  • → déplie un dossier, ← le replie

La meilleure idée du Finder.

Parcourez de longues arborescences de gauche à droite et voyez toujours où vous êtes. La dernière colonne affiche un aperçu du fichier sélectionné.

  • L’Explorateur de fichiers n’a pas de vue en colonnes
  • Les flèches passent d’une colonne à l’autre

Faite pour les photos.

Un grand aperçu, une pellicule en dessous et les détails du fichier sur le côté. Les flèches font défiler le dossier.

  • Marche aussi pour les documents et les vidéos
  • Espace pour un Aperçu rapide en grand

02Aperçu rapide

Appuyez sur Espace. Voyez tout.

Prévisualisez photos, vidéos, PDF, tableurs et textes sans ouvrir d’autre app. Et oui, vous pouvez corriger cette faute de frappe directement dans l’aperçu.

  • Modifiez sur placeLes fichiers texte et CSV se modifient dans l’aperçu. Essayez le tableur ci-dessus. Dans l’app, Ctrl+S enregistre.
  • Passez au suivantLes flèches passent au fichier suivant sans fermer l’aperçu.
  • Vidéo avec commandesLecture, déplacement dans la vidéo et coupure du son. Les commandes s’effacent au bout d’un instant.

03Fonctions

Petits détails. Grande différence.

Conçu à partir d’une étude attentive du Finder de macOS, puis comparé à l’Explorateur de fichiers et à Files pour que rien d’utile ne manque. Toutes les cartes ci-dessous fonctionnent.

Palette de commandes

Appuyez sur Ctrl ⇧ P et tapez. Toutes les commandes, avec leur raccourci. Essayez : tapez « colon » ou « sombre », puis Entrée.

    08FAQ

    Les questions qu’on nous pose.

    Existe-t-il un Finder pour Windows ?

    Oui, le voici. Windows Finder est un gestionnaire de fichiers gratuit et open source pour Windows 10 et 11 qui reprend le Finder de macOS : même disposition de fenêtre, vues icônes, liste, colonnes et galerie, onglets, Aperçu rapide, étiquettes et Lire les informations.

    Peut-on avoir le Finder de macOS sur Windows 11 ?

    macOS ne tourne pas sur Windows, mais Windows Finder vous donne un gestionnaire de fichiers façon Finder qui fonctionne sur vos vrais fichiers Windows, disques, OneDrive, distributions WSL et Corbeille.

    Comment avoir la vue en colonnes sur Windows ?

    L’Explorateur de fichiers n’a pas de vue en colonnes. Installez Windows Finder et appuyez sur Ctrl 3 dans n’importe quel dossier pour le parcourir en colonnes, avec un aperçu du fichier sélectionné dans la dernière colonne.

    Existe-t-il un Aperçu rapide (Quick Look) pour Windows ?

    Oui. Dans Windows Finder, sélectionnez un fichier et appuyez sur Espace pour prévisualiser images, texte, CSV, PDF et vidéo, sans ouvrir d’autre app. Les fichiers texte et CSV se modifient directement dans l’aperçu.

    Windows Finder est-il gratuit ?

    Oui. Il est gratuit et publié sous licence MIT. Pas de publicité, pas de compte, pas de télémétrie.

    Remplace-t-il l’Explorateur de fichiers ?

    Seulement si vous le voulez. Un réglage facultatif, par utilisateur, en fait le gestionnaire de dossiers par défaut et s’annule en un clic. L’Explorateur reste sur votre PC et Win+E fonctionne toujours.

    Pourquoi SmartScreen affiche-t-il un avertissement ?

    L’installateur n’est pas encore signé, SmartScreen ne le reconnaît donc pas. Cliquez sur Informations complémentaires, puis Exécuter quand même. Le code source et les versions publiées sont publics sur GitHub.

    Est-ce sûr pour mes fichiers ?

    Supprimer envoie à la Corbeille, les actions irréversibles demandent confirmation, et rien n’est envoyé sur le réseau. Les modifications du registre (seulement si vous les demandez) restent dans votre profil utilisateur.

    Est-ce affilié à Apple ?

    Non. C’est un projet open source indépendant inspiré du Finder de macOS. Finder et macOS sont des marques d’Apple Inc.
