# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

* Be kind and constructive; critique code, not people.
* No harassment, discrimination, personal attacks or unwelcome sexual attention.
* Assume good faith; help newcomers.

Maintainers may remove comments, commits or contributors that break these rules. Report problems privately to the repository owner.
