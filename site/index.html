What you get

Everything you miss from the Mac Finder, plus what Windows needs.

Built from a reverse-engineering study of the macOS Finder, then cross-checked against File Explorer and the Files app so nothing useful is left out.

⌘

Four views, per folder

Icons with free placement, List with expandable folders, Columns with a rich preview, Gallery with a thumbnail strip. Each folder remembers its own view, sort, grouping and icon size.

␣

Quick Look

Press Space to preview images, text, CSV, PDF and video with playback controls. Edit text and CSV right inside the preview.

⊞

Tabs and windows

Tabs, tab overview, reopen closed tab, spring-loaded folders, mouse back and forward buttons, Go to Folder and Connect to Server.

●

Tags and Get Info

Colour tags with their own sidebar section, and a full Get Info panel with sizes, dates, kind, permissions and Open With.

⌃

Command palette

Press Ctrl+Shift+P to find any command, with its shortcut, from a single search box.

⊕

Real Windows integration

“More Options…” opens the genuine Explorer context menu (Git, 7-Zip, Send to, Properties). WSL distros in the sidebar, Recycle Bin, OneDrive, network, Terminal and administrator launch.

◐

Light, dark and accents

Follows Windows, switches live, eight accent colours, rounded window with traffic-light buttons, just like the Mac.

文

Your language

English, Français, Español and Deutsch, chosen automatically from your Windows language. Adding a language is one column in a text file.

Install

Build it in two minutes.

No installer yet. You need Windows 10 or 11, Rust and the Visual Studio C++ build tools.

  1. Clone the repository.
  2. Run cargo build --release.
  3. Launch WindowsFinder.exe. Press Ctrl+, for settings.
git clone https://github.com/EvanPluchart/windows-finder.git
cd windows-finder
cargo build --release
.\target\release\WindowsFinder.exe

Under the hood

Rust, GPU-drawn, reverse-engineered.

The interface is drawn on the GPU with GPUI. Disk, search and previews run off the UI thread. Geometry, colours and behaviour come from measuring the real Finder; features were cross-checked against File Explorer and Files with the REA reverse-engineering toolkit. The reports are in the repository.

FAQ

Questions people ask.

Is there a Finder for Windows?

Yes, this is it. Windows Finder is a free, open source file manager for Windows 10 and 11 that recreates the macOS Finder: the same window layout, icon, list, column and gallery views, tabs, Quick Look previews, tags and Get Info.

Can I get the macOS Finder on Windows 11?

macOS itself does not run on Windows, but Windows Finder gives you a Finder-style file manager that works on your real Windows files, drives, OneDrive, WSL distributions and Recycle Bin.

Is Windows Finder free?

Yes. It is released under the MIT license. Use it, change it and contribute on GitHub.

Does it replace File Explorer?

Only if you want. An optional per-user setting makes it the default folder handler and can be undone in one click. File Explorer stays on your PC and Win+E keeps working. “More Options…” even shows the native Explorer menu with all your shell extensions.

Is it safe to use on my files?

Deleting sends files to the Recycle Bin, irreversible actions ask for confirmation, and nothing is sent over the network. Registry changes (only when you ask) stay under your user profile.

Is it affiliated with Apple?

No. It is an independent open source project inspired by the macOS Finder. Finder and macOS are trademarks of Apple Inc.
